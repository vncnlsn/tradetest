What changed in this build.

Built in this version

  • Goal mode with actual vs goal vs projected equity lines
  • Required pace, ahead/on pace/behind, and gap measurement
  • Trade tags plus performance by tag
  • Performance by day of week and ticker
  • Auto-generated insights panel
  • CSV import with duplicate detection and feedback
  • Basic PDF import via text extraction
  • Drag-and-drop dashboard layout with persistence
  • Journal notes in calendar sessions

Rules of the road

  • No cloud account, no social layer, no bloated charting
  • Local-first storage in your browser
  • Export often if you want a backup
  • Press N to open the log modal
Backup status: -

Data model

Accounts store the starting value and date. Trades are closed trades only. Deposits and withdrawals adjust capital but do not affect trading P&L. Tags are comma-separated and can be user-defined per trade.
